# C_study

C/C++ 基础算法知识学习记录，包含数据结构、算法竞赛模板、语法练习等内容。

## 内容分类

- **前缀和与差分**：`一维前缀和模板.cpp`、`二维前缀和模板.cpp`、`一维差分处理区间增量问题.cpp`、`二维差分增量模板.cpp`
- **数据结构**：`栈操作.cpp`、`LRU页面置换算法.cpp`
- **算法竞赛题目**：`洛谷p1094.cpp`、`博弈论.cpp`、`周赛贪心题.cpp`、`周赛字符串典题.cpp`、`周赛题目（超时）.cpp`、`头歌好题.cpp`
- **字符串处理**：`字符串中数字字符个数.cpp`、`查找字符串中首次出现字符.cpp`、`判断字符串是否为回文.cpp`
- **数学与数论**：`完美平方数.cpp`、`数字1出现的次数统计.cpp`、`Collatz猜想.cpp`、`前100个素数的输出.c`
- **指针与结构体**：`指针运用示例：除法.c`、`结构体示例.c`
- **递归与基础**：`动态内存分配.c`、`井字棋胜利判定.c`、`猜数游戏.c`、`数组题.cpp`、`爱心打印.cpp`、`统计数字出现次数.c`、`原始模板.cpp`
- **学习笔记**：`markdownfile/` 目录下包含 `.md` 格式的学习笔记

## 运行方式

C++ 文件使用 `g++` 编译，C 文件使用 `gcc` 编译：

```bash
# 编译 C++ 文件
g++ 一维前缀和模板.cpp -o prefix && ./prefix

# 编译 C 文件
gcc 猜数游戏.c -o guess && ./guess
```
